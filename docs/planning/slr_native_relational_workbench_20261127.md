# Native relational workbench bridge

SLR PR #79 is the native Rust/Postgres owner. Lean #112 and Agda own proof specifications. SensibLaw is a historical donor, not the production engine.

`itir.relational.inspect` exposes the native family, prepared revision and original numeric relation query readbacks without reconstructing a Python ontology or parser. Operator config: absolute path `ITIR_SLR_NATIVE_EXECUTABLE` and original database configuration. The command allowlist is read-only; no actor-supplied binary, SQL, review authority or external source edit. S29 revision actions remain explicit native operator actions. Native response preserves exact source, sign, residual and proof boundary fields.

User-story scope: ITIR-US-17, WIKI-US-04 / SL-US-41, SL-US-15–19 inspection/reconciliation; does not yet replace all legacy wiki packet tools, implement a GUI, or pay semantic equivalence or identity. Formal routing and referee certification retain their existing owners. Local pytest and native execution pending.
